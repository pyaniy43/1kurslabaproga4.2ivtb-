# 1kurslabaproga4.2ivtb-
Лабораторная работа №4.2
Цель: Научиться создавать простые графические интерфейсы с использованием библиотеки tkinter, организовывать обработку событий и интегрировать ранее разработанные программные модули в единое приложение. Закрепить понимание работы выбранной структуры данных через её визуальное представление.
• На основе реализации структуры данных из лабораторной работы 4.1. необходимо разработать оконное приложение с графическим интерфейсом на Python.
• Все операции со структурой данных должны выполняться исключительно через вызовы функций отдельно оформленных библиотечных модулей.
• Необходимо предусмотреть реализацию, как минимум двух модулей: один на С++, второй - Python.
• Для получения дополнительных баллов, необходима реализация двух вариантов С++ модуля : с использованием структур на динамической памяти и с использованием контейнеров и адаптеров STL.
• Интерфейс должен адекватно реагировать на попытку выполнить некорректную операцию (например, Pop из пустого стека), выводя понятное сообщение, без аварийного завершения программы.
• Визуализации должна обновляться после каждой успешной операции.
• В качестве ответа необходимо прикрепить отчет и ссылку на репозиторий с проектом.

Задача представляет собой оконное приложение на Python с графическим интерфейсом (`tkinter`) для работы со структурой данных **стек**.  
Особенность работы — все операции со стеком выполняются **только через функции отдельных модулей**, реализованных на **Python** и **C++**.

## Что было сделано

- Разработан GUI с полями ввода, кнопками операций (`Push`, `Pop`, `Peek`, `Clear`) и областью визуализации стека.
- Создан Python-модуль `stack_py.py`, реализующий стек на основе списка (`list`) — динамический, без ограничения размера.
- Написаны два C++ модуля, скомпилированных в динамические библиотеки (`.dll`):
  - `stack_cpp_dynamic.cpp` — стек на указателях (связный список), ручное управление памятью.
  - `stack_cpp_stl.cpp` — стек с использованием контейнера `std::stack` и пар `std::pair`.
- Реализована обёртка `stack_cpp_wrapper.py`, которая через `ctypes` подключает C++ DLL и предоставляет такие же методы (`push`, `pop`, `peek`, `get_all` и т.д.).
- В интерфейс добавлен переключатель для выбора текущей реализации стека (Python / C++ Dynamic / C++ STL). При переключении создаётся новый экземпляр соответствующего модуля.
- Обеспечена корректная обработка ошибок: при попытке `Pop` из пустого стека или переполнении (если бы был лимит) выводится понятное уведомление, программа не завершается аварийно.
- После каждой операции автоматически обновляется визуализация стека.
